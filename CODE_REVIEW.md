### Наступні кроки:

1. Створити .env файл з реальними даними
2. Встановити залежності: `pip install -r requirements.txt`
3. Ініціалізувати базу даних: `python init_db.py`
4. Додати першого адміністратора: `python add_admin.py <telegram_id> OWNER 5`
5. Запустити бота: `python main.py`
6. Запустити веб-сервер: `python web_server.py`
7. Провести тестування функціоналу
