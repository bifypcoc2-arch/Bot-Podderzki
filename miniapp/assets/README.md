# Иллюстрации мини-приложения

Все файлы — SVG 512×512, одна палитра с темно-фиолетовой темой.
Подключает их `miniapp/assets.js`. Имена файлов важны: код ищет
ресурсы по пути `assets/<папка>/<имя>.svg`. Если файл не найден,
на месте остаётся старый символ или эмодзи — приложение не ломается.

## pets/ — виды питомца

Имя файла совпадает со значением `PetType` в `database/models.py`.

| Файл | Вид |
| --- | --- |
| `cat.svg` | кошка |
| `dog.svg` | собака |
| `fox.svg` | лиса |
| `panda.svg` | панда |
| `rabbit.svg` | кролик |
| `hedgehog.svg` | ёжик |
| `penguin.svg` | пингвин |

На стадиях «Зарождение» и «Яйцо» вид ещё не выбран, там остаются эмодзи.

## stats/ — показатели

| Файл | Где видно |
| --- | --- |
| `hunger.svg` | кольцо «Голод» |
| `mood.svg` | кольцо «Счастье» |
| `clean.svg` | кольцо «Гигиена» |
| `energy.svg` | кольцо «Энергия» |
| `xp.svg` | полоса опыта, серия входов |
| `paws.svg` | валюта и полоса «Лапки» |

## actions/ — кнопки ухода

Имя файла совпадает с `data-action` кнопки: `feed`, `play`, `wash`,
`sleep`, `train`.

## nav/ — нижняя навигация

`home.svg` — Дом, `games.svg` — Игры, `shop.svg` — Магазин,
`profile.svg` — Профиль. Закладка «Питомец» использует `ui/avatar.svg`.

## games/ — мини-игры

`dice.svg` — Кости духов, `numbers.svg` — Шёпот цифр,
`wordle.svg` — Слово из тумана. Привязка идёт по заголовку карточки,
так что при переименовании игры надо поправить `GAME_ICONS` в `assets.js`.

## ui/ — общие элементы

`avatar.svg` — круглый призрак, `back.svg` — назад, `cart.svg` — корзина,
`check.svg` — подтверждение. Последние три пока в запасе под корзину
магазина и подтверждение покупки.

## shop/ — товары

У товаров в базе нет поля с картинкой, поэтому `assets.js` подбирает
изображение по корню слова в названии, а если не совпало — по типу
товара.

Еда: `bowl.svg` (миска, она же запасная для любой еды), `cupcake.svg`,
`potion.svg`, `soup.svg`, `berries.svg`, `meat.svg`.

Игрушки: `ball.svg` (запасная для любой игрушки), `yarn.svg`,
`spinner.svg`, `mouse.svg`, `dreamcatcher.svg`.

Слова-ключи для подбора перечислены в `ITEM_KEYWORDS`. Новый товар лучше
называть так, чтобы в имени был корень из списка — тогда картинка
подтянется сама.

## achievements/ — достижения и значки

`bag.svg`, `book.svg`, `brush.svg`, `care.svg`, `chest.svg`, `crown.svg`,
`crystal.svg`, `dice.svg`, `friendship.svg`, `heart.svg`, `infinity.svg`,
`shield.svg`, `sleep-mask.svg`, `sprout.svg`, `star.svg`.

Подбор — тоже по корню слова (`ACHIEVEMENT_KEYWORDS`), запасной вариант —
`star.svg`. `shield.svg` стоит у полосы «Дисциплина».
